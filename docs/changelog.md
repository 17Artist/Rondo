# 更新日志

本页记录 Rondo 的版本变更。版本号遵循语义化版本规范。

## 未发布

### 修复

- 注册插件权限节点及默认值，普通玩家现在可以正常使用 `/money` 系列命令（此前未注册权限节点，Bukkit 按 OP 处理，导致非 OP 玩家被拒绝）。
- 余额、排行榜、占位符等展示统一采用四舍五入，修复当余额小数位多于货币精度时可能抛出异常的问题。
- 金额在写入前统一归一到货币精度，避免存储超出精度的小数。
- 离线玩家存入也会校验余额上限，与在线玩家行为保持一致。
- 转账与兑换在回滚时改用强制存入，确保异常情况下不会丢失玩家资金。
- 货币兑换的货币 ID 匹配改为大小写不敏感，与货币注册表保持一致。
- 排行榜排名查询不再在主线程发起阻塞式数据库查询。
- 兑换周期限购的"每周"起点固定为周一，不再受系统区域设置影响。
- 流水日志在多次写入失败后，丢弃前会先将明细输出到控制台，避免静默丢失。

## 1.0.0

首个正式版本。

- 配置驱动的多货币系统，支持任意数量的货币
- 货币兑换系统，支持比率、最小数量与周期限购
- Redis 跨服同步，基于 Lua 原子事务保证多服一致性
- 排行榜系统，定时刷新
- 完整的交易流水日志，支持异步写入与过期清理
- Vault 与 PlaceholderAPI 集成
- SQLite 与 MySQL 存储
- 面向其他插件的 `RondoAPI` 与可取消的经济事件
