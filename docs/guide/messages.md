# 消息配置

消息配置文件位于 `plugins/Rondo/messages.yml`，支持完全自定义所有插件输出的文本。

## 变量说明

消息中使用 `{变量名}` 格式的占位符，运行时自动替换：

| 变量               | 说明     |
|------------------|--------|
| `{prefix}`       | 消息前缀   |
| `{color}`        | 货币颜色代码 |
| `{symbol}`       | 货币符号   |
| `{display_name}` | 货币显示名  |
| `{balance}`      | 余额     |
| `{amount}`       | 金额     |
| `{player}`       | 玩家名    |
| `{target}`       | 目标玩家名  |
| `{sender}`       | 发送方玩家名 |
| `{tax}`          | 税额     |
| `{rank}`         | 排名     |
| `{page}`         | 当前页码   |
| `{total_pages}`  | 总页数    |
| `{my_rank}`      | 自己的排名  |
| `{time}`         | 时间     |
| `{action}`       | 操作类型   |
| `{source}`       | 来源标识   |
| `{id}`           | 货币 ID  |
| `{name}`         | 名称     |

部分消息使用专属变量。兑换成功消息（`exchange-success`）中，源货币和目标货币各有一组：

| 变量                                          | 说明           |
|---------------------------------------------|--------------|
| `{from_color}` / `{from_symbol}` / `{from_amount}` | 源货币的颜色、符号、数量 |
| `{to_color}` / `{to_symbol}` / `{to_amount}`       | 目标货币的颜色、符号、数量 |

> 不同消息能用的变量不完全一样，具体可以参考 `messages.yml` 里各条目的默认值。

## 颜色代码

支持 Minecraft 标准颜色代码（`§` 前缀）：

```
§0 黑色  §1 深蓝  §2 深绿  §3 深青
§4 深红  §5 深紫  §6 金色  §7 灰色
§8 深灰  §9 蓝色  §a 绿色  §b 青色
§c 红色  §d 粉色  §e 黄色  §f 白色
§l 粗体  §o 斜体  §n 下划线  §m 删除线
§k 混淆  §r 重置
```
